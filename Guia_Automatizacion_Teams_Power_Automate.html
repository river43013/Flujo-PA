Requisito crítico

¿El Excel tiene que estar compartido?

No necesariamente. Puede ser privado. Lo importante es que esté alojado en tu OneDrive for Business corporativo y sea accesible para Power Automate.

IMPORTANTE: El archivo no tiene que estar compartido con otras personas, pero sí tiene que estar alojado en tu OneDrive corporativo. Power Automate no puede leer directamente un Excel que solo está guardado en tu PC.
❌ IncorrectoC:\Users\Usuario\Desktop\Recordatorio.xlsx
✅ CorrectoOneDrive corporativo → Mis archivos → Recordatorio.xlsx

Configuración esperada en Power Automate

CampoValor
LocationOneDrive for Business

File/Recordatorio.xlsx

En algunas organizaciones el OneDrive personal se visualiza como Mis archivos, pero la biblioteca aparece en Power Automate como Documentos. Es normal.

3
Preparación de datos

Preparar correctamente el Excel

El archivo puede llamarse Recordatorio.xlsx y debe contener, como mínimo, una columna llamada exactamente Correo.

Correo
usuario1@empresa.com
usuario2@empresa.com
usuario3@empresa.com

Convertir los datos en una Tabla real

  1. Selecciona el rango completo incluyendo el encabezado Correo.
  2. Presiona Ctrl + T.
  3. Marca La tabla tiene encabezados.
  4. Confirma y revisa en Diseño de tabla / Table Design el nombre asignado.
  5. Puede llamarse Tabla1 o Table1.
  6. Guarda el archivo.
¿Cómo sé si realmente es una Tabla?
Haz clic dentro de los datos. Si aparece la pestaña contextual Diseño de tabla / Table Design, sí es una tabla estructurada.

Evitar filas vacías

La tabla debe terminar exactamente en la última fila con información. Una tabla que incluye filas aparentemente vacías hará que Power Automate intente procesarlas.

Síntoma típico: Apply to each procesa más registros de los esperados y Get user profile (V2) falla con un error como id may not be null or empty.

Corrige el rango usando Diseño de tabla → Cambiar tamaño de tabla o elimina las filas vacías de la tabla.

Acción 1

List rows present in a table

Agrega Excel Online (Business) → List rows present in a table.

¿Table muestra “No items”?

Normalmente significa que Power Automate encontró el archivo, pero no detectó una Tabla estructurada. Abre Excel, convierte el rango con Ctrl + T, guarda, cierra el archivo y vuelve a seleccionarlo en Power Automate.

6
Acción 2

Apply to each

Agrega Control → Apply to each. En Select an output from previous steps selecciona body/value o simplemente value de List rows present in a table.

Qué significa: value es la colección completa de filas que devolvió Excel. El bucle tomará una fila a la vez.
7
Acción 3

Get user profile (V2)

Dentro de Apply to each, agrega Office 365 Users → Get user profile (V2).

En User (UPN) debes pasar el correo de la fila actual.

Correo actual
items('Apply_to_each')?['Correo']

items('Apply_to_each') obtiene la fila actual y ['Correo'] extrae el valor de la columna Correo.

8
Acción 4

Create a chat

Agrega Microsoft Teams → Create a chat, también dentro de Apply to each.

En Members to add utiliza el Id devuelto por Get user profile (V2).

Si no aparece Id
outputs('Get_user_profile_(V2)')?['body/id']
Title: déjalo vacío. Para este flujo no necesitas un título de chat.
9
Acción 5

Get an @mention token for a user

Agrega Microsoft Teams → Get an @mention token for a user.

En el campo User, usa nuevamente el correo de la fila actual:

items('Apply_to_each')?['Correo']
Por qué hacerlo así: escribir manualmente @Nombre puede quedar como texto plano. El token genera una mención real de Teams.

Acción 6

Post message in a chat or channel

Agrega Microsoft Teams → Post message in a chat or channel.

CampoConfiguración
Post asUser
Post inChat de grupo
Chat de grupoEnter custom value → Conversation ID de Create a chat
No selecciones un chat histórico manualmente. El chat debe cambiar de forma dinámica en cada iteración usando el Conversation ID que devuelve Create a chat.

Configurar el mensaje

Escribe Hola , inserta el contenido dinámico generado por Get an @mention token for a user y luego continúa con el mensaje.

Hola [Mention Token] 👋 Te escribo para recordarte que tienes pendiente completar...
Resultado esperado: el destinatario verá un mensaje normal enviado por tu usuario corporativo y con una mención real.

Validación

Guardar y realizar una prueba

  1. Haz clic en Save.
  2. Prueba primero con uno o dos correos.
  3. Ve a Test → Manually → Run flow.
  4. Verifica que cada mensaje llegue al chat correcto.
  5. Confirma que el remitente sea tu usuario y que la mención funcione.
Nunca estrenes el flujo con toda la base.

1 usuario → 2 usuarios → 5 usuarios → base completa.

Troubleshooting

Errores que encontramos

Error 1 · Table = No items

Causa: el Excel no tenía una Tabla real.
Solución: convertir el rango con Ctrl + T.

Error 2 · Power Automate no muestra la columna Correo

Utiliza fx y pega:

items('Apply_to_each')?['Correo']
Error 3 · No aparece Id

Utiliza esta expresión:

outputs('Get_user_profile_(V2)')?['body/id']
Error 4 · “Chat de grupo” muestra chats existentes

No selecciones ninguno manualmente. Usa Enter custom value y luego inserta Conversation ID de Create a chat.

Error 5 · El run termina Failed aunque algunos mensajes llegaron

Las causas más probables son filas vacías, correos mal escritos, usuarios cesados, cuentas desactivadas o usuarios que ya no existen en Microsoft 365.

¿Qué pasa con usuarios inactivos?

Puede fallar Get user profile (V2), Create a chat o Get an @mention token. Los usuarios válidos pueden haber recibido correctamente su mensaje aunque la ejecución general quede como Failed. En esta versión se prioriza simplicidad y no se implementa Scope + Configure run after.
